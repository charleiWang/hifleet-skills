# TC-04 Missing route distance

Input:

```json
{
  "cargoQty": 50000,
  "loadPort": "Ras Tanura",
  "dischargePort": "Rotterdam",
  "loadPortCoord": { "lng": 50.1667, "lat": 26.65 },
  "dischargePortCoord": { "lng": 4.4667, "lat": 51.9167 },
  "freightRate": 25,
  "bunkerPrice": 600,
  "speedKn": 12,
  "portCharges": 140000
}
```

Expected:

```json
{
  "status": "needs_route_distance_api",
  "distanceApi": {
    "url": "/hifleetrouteapi/getNewRoute",
    "params": {
      "start": "50.1667,26.65",
      "end": "4.4667,51.9167"
    }
  },
  "missing": ["seaConsumptionMtPerDay", "portConsumptionMtPerDay"],
  "computed": {
    "grossFreight": "1250000.00"
  }
}
```

Checks:

- With port coordinates but no `distanceNm`, prepare or call `/hifleetrouteapi/getNewRoute` (or `ROUTEBYPOSITION_TOKEN_SKILL.md`).
- Do not invent Suez / Cape / detour distances.
- May output income items that are already determined.
- Explicitly list missing inputs or mark “needs input / needs API”.

# TC-07 Port distance API response normalization

Input:

```json
{
  "request": {
    "url": "/hifleetrouteapi/getNewRoute",
    "params": {
      "start": "120.316,36.066",
      "end": "118.58,-20.31",
      "avoidareaid": "669"
    }
  },
  "response": {
    "status": "success",
    "nmile": "4012.35",
    "ecadis": "12.50",
    "waypoints": [
      {
        "dis": "4008.75",
        "ecadis": "11.25"
      }
    ]
  }
}
```

Expected:

```json
{
  "ok": true,
  "distanceNm": "4008.75",
  "ecaDistanceNm": "11.25",
  "route": {
    "requestParams": {
      "start": "120.316,36.066",
      "end": "118.58,-20.31",
      "avoidareaid": "669"
    }
  }
}
```

Checks:

- Prefer `waypoints[0].dis` over `nmile`.
- Prefer `waypoints[0].ecadis` over top-level `ecadis`.
- Keep request params for distance provenance.

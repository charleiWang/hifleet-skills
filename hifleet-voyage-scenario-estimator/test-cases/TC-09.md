# TC-09 Port suggest fills coordinates (SUGGESTION_LOCATION_API)

Input:

```json
{
  "loadPort": "Shanghai",
  "dischargePort": "Rotterdam",
  "loadPortCoord": null,
  "dischargePortCoord": null,
  "api": {
    "url": "/openclaw/vessel/charter/liner/ports/suggest/location",
    "method": "GET",
    "query": {
      "keyword": "Shanghai",
      "from": "0",
      "size": "5",
      "cjwharf": "0",
      "i18n": "cn"
    }
  },
  "response": {
    "msg": "SUCCESS",
    "total": 4,
    "status": "1",
    "data": [
      {
        "portId": "27999",
        "portName": "Shanghai,CN",
        "portNameCn": "上海,CN",
        "lat": 31.3797833,
        "lon": 121.5841333,
        "countryCodeIso2": "CN",
        "_score": 197.02026
      },
      {
        "portId": "467489",
        "portName": "nangang(shanghai),CN",
        "portNameCn": "南港（上海）,CN",
        "lat": 30.840917,
        "lon": 121.838585,
        "countryCodeIso2": "CN",
        "_score": 40.795395
      }
    ]
  }
}
```

Expected:

```json
{
  "status": "ok",
  "apiDoc": "SUGGESTION_LOCATION_API.md",
  "selected": {
    "portId": "27999",
    "label": "上海,CN",
    "coord": { "lng": 121.5841333, "lat": 31.3797833 },
    "note": "multiple hits → temporarily use data[0]"
  },
  "next": {
    "dischargePort": "call suggest/location again with keyword=Rotterdam; use data[0]",
    "afterBothPorts": "call ROUTEBYPOSITION_TOKEN_SKILL with start/end lon,lat"
  }
}
```

Checks:

- When coordinates are missing, call **`GET …/ports/suggest/location`** (see **`SUGGESTION_LOCATION_API.md`**); do not use `portguide/getPort/token`.
- Multiple hits → **temporarily use `data[0]`** as effective coords/`portId`; state the auto-selected port.
- Prefer `portNameCn` for display label, else `portName`; map coords to `{ lng: lon, lat }`.
- Call once per port (separate `keyword` for load and discharge).
- After both ends are resolved, call **`ROUTEBYPOSITION_TOKEN_SKILL.md`** for voyage distance.
- Never fabricate `portId` or coordinates.

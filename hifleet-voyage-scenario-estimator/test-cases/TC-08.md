# TC-08 Missing port coordinates blocks distance API

Input:

```json
{
  "loadPort": "Qingdao",
  "dischargePort": "Port Hedland",
  "loadPortCoord": null,
  "dischargePortCoord": { "lng": 118.58, "lat": -20.31 }
}
```

Expected:

```json
{
  "status": "needs_input",
  "missing": ["loadPort.lng", "loadPort.lat"],
  "message": "Port coordinates missing; cannot call distance API"
}
```

Checks:

- Do not build distance API params from port names alone.
- Do not invent lat/lon.

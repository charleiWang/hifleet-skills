# TC-03 Multi-grade fuel cost

Input:

```json
{
  "seaDays": 10,
  "portDays": 4,
  "fuelMtByType": {
    "VLSFO": { "sea": 280, "port": 10 },
    "LSMGO": { "sea": 0, "port": 6 }
  },
  "bunkerPriceByType": {
    "VLSFO": 590,
    "LSMGO": 780
  }
}
```

Expected:

```json
{
  "fuelCost": "175780.00"
}
```

Checks:

- `VLSFO = (280 + 10) * 590 = 171100`.
- `LSMGO = (0 + 6) * 780 = 4680`.
- Total fuel cost is `171100 + 4680`.

# TC-10 Latest bunker prices map to bunkerPrice (COMMODITY_PRICES_LATEST_TOKEN_API)

Input:

```json
{
  "cargoQty": 50000,
  "loadPort": "Ras Tanura",
  "dischargePort": "Rotterdam",
  "freightRate": 25,
  "bunkerPrice": null,
  "bunkerHub": "Singapore",
  "speedKn": 12,
  "api": {
    "url": "/commodity/prices/latest/token",
    "method": "GET",
    "auth": "api_key or x-api-key"
  },
  "response": {
    "status": "1",
    "msg": "SUCCESS",
    "data": [
      {
        "id": "9376",
        "reportDate": "2026-07-07",
        "type": "zhoushan",
        "priceVlsfo": 643,
        "priceIfo": 466,
        "priceMgo": 958
      },
      {
        "id": "9377",
        "reportDate": "2026-07-07",
        "type": "Singapore",
        "priceVlsfo": 633,
        "priceIfo": 448,
        "priceMgo": 912
      },
      {
        "id": "9378",
        "reportDate": "2026-07-07",
        "type": "Rotterdam",
        "priceVlsfo": 577,
        "priceIfo": 448,
        "priceMgo": 956.5
      }
    ]
  }
}
```

Expected:

```json
{
  "status": "ok",
  "apiDoc": "COMMODITY_PRICES_LATEST_TOKEN_API.md",
  "selected": {
    "type": "Singapore",
    "reportDate": "2026-07-07",
    "bunkerPriceByType": {
      "VLSFO": 633,
      "HSFO": 448,
      "LSMGO": 912
    },
    "bunkerPrice": 633
  },
  "note": "cite hub type + reportDate when quoting prices"
}
```

Checks:

- When `bunkerPrice` is missing, call **`GET /commodity/prices/latest/token`** (see **`COMMODITY_PRICES_LATEST_TOKEN_API.md`**).
- Match hub by `bunkerHub` / `type` (here `Singapore`); never invent prices.
- Map: `priceVlsfo→VLSFO`, `priceIfo→HSFO`, `priceMgo→LSMGO`.
- Single-grade estimate may use `priceVlsfo` as `bunkerPrice`; always cite `type` and `reportDate`.
- Do not overwrite user-supplied bunker prices unless the user asks to refresh.

# TC-11 Route-by-position response normalization (ROUTEBYPOSITION_TOKEN_SKILL)

Input:

```json
{
  "request": {
    "url": "/routepoints/routebyposition/token",
    "method": "GET",
    "params": {
      "api_key": "{key}",
      "usertoken": "{key}",
      "start": "-81.01,13.16",
      "end": "86.90,11.23",
      "avoidareaid": "669,671",
      "viewpoint": ""
    }
  },
  "response": {
    "status": "success",
    "start": "3.812706152462681,54.459206024127575",
    "end": "85.76410072157188,4.403802717417645",
    "viewpoint": "",
    "nmile": 7321,
    "passAvoidArea": [
      {
        "areaid": 671,
        "ename": "Dover Strait",
        "name": "多菲尔海峡"
      },
      {
        "areaid": 669,
        "ename": "Suez Canal",
        "name": "苏伊士运河"
      }
    ],
    "waypoints": [
      {
        "dis": 7321.5,
        "ecadis": 518.5,
        "piracydis": 1569.1,
        "waypoints": [
          [3.812706152462681, 54.459206024127575],
          [85.76410072157188, 4.403802717417645]
        ]
      }
    ]
  }
}
```

Expected:

```json
{
  "ok": true,
  "apiDoc": "ROUTEBYPOSITION_TOKEN_SKILL.md",
  "distanceNm": 7321.5,
  "ecaDistanceNm": 518.5,
  "piracyDistanceNm": 1569.1,
  "route": {
    "requestParams": {
      "start": "-81.01,13.16",
      "end": "86.90,11.23",
      "avoidareaid": "669,671",
      "viewpoint": ""
    },
    "auth": "api_key + usertoken required"
  }
}
```

Checks:

- Call **`GET /routepoints/routebyposition/token`** (see **`ROUTEBYPOSITION_TOKEN_SKILL.md`**).
- `start` / `end` required as **`lon,lat`**; if coords are missing, resolve via **`SUGGESTION_LOCATION_API.md`** first — never build params from port names alone.
- Prefer `waypoints[0].dis` over `nmile` → `distanceNm`.
- `waypoints[0].ecadis` → `ecaDistanceNm`.
- Keep `requestParams` (including `avoidareaid` / `viewpoint`) and raw `route.response` for provenance.
- Never fabricate distance, track points, or avoid-area geometry.

# 能力路由与 When to Run（与 `SKILL.md` 对应章节全文一致，不得删减）

## 能力路由（必读）

助手在回答前**必须先**判断用户意图落在哪条路由；**两套流程互不替代**，避免用翻邮件代替班轮船期接口，也避免把「邮件里出现的船期字样」与「班轮船期查询」混为一谈。

### 路由 A — 船货盘邮件（既有流程）

- **含义**：从用户邮箱与向量记忆中检索、解析**船盘 / 货盘 / 与租船揽货相关的邮件内容**（含邮件正文里可能出现的「船期」等字样，但本质仍是**邮件事实**）。  
- **执行**：完成 **Workflow 0** 中与邮件检索相关的步骤（第 2～4 步，含记忆与邮箱就绪检查），必要时 **Workflow 1**，再进入 **Workflow 2** 全文。**不得**删减、重排 **2.1～2.7** 及 **2.3.5 / 2.4 / 2.4.1** 的既定逻辑（全文见 **`WORKFLOW_2_MAIL.md`**）。  
- **典型说法**：「邮件里」「最近船盘/货盘」「帮我查邮箱」「某时间段邮件」等。

### 路由 B — 船期（HiFleet 服务端数据，经 API 拉取）

- **含义**：用户要的是 **HiFleet 在 `ttseapi` 上维护的班轮船期**（装/卸港、Laycan、船名、航线等），**不是**从用户自己的邮件里检索。**未解锁**记录仅可展示白名单字段（Laycan、装/卸港、`id`、航线），敏感项须 **`/unlock`**；**已解锁**须标注 **`（已解锁）`** 且勿再提示解锁（详见 **`SCHEDULE_API.md`**、**`WORKFLOW_OUTPUT.md`**）。  
- **触发关键词（示例，非穷举）**：船期、班轮、航线时刻、schedule、line、班次、周班；或「从 A 港到 B 港**有没有船**/**哪天开**」且语境为**查公司数据**而非「谁发来的邮件里的船期」。  
- **执行**：仅 **Workflow 3**——先检查 **`hifleet_api_key`**，再按 **`SCHEDULE_API.md`** 调用 **GET `/ports/suggest`**（**装、卸都提则各取 1 条，解出两枚 `portId`）→ **`POST /schedules?sk=`**（分页直至 **`data` 全量**，`params` 中两港须**同时**带 `portid`+`dischargingPortid` 当用户已明确两港）→ **逐条全部**展示；**禁止**只带装港 `portid` 再靠港名筛卸港。用户同意扣积分后再 **`POST /unlock?...`**。详见 **`SCHEDULE_API.md`**。  
- **典型查询维度**：装货港、卸货港、受载/解约日窗（请求体仍用 `openDateStart` / `openDateEnd` 等；**对用户输出**合并为 **Laycan** 一行，见 **`SCHEDULE_API.md`**），**以 portId 为唯一**查询主键。  
- **仍走路由 A 的情况**：用户明确说「**邮件里**有没有」「**谁发来的**船期」「**货盘/船盘**里写的开船日」等——本质仍是邮件检索。

### 同轮对话混合

用户一句话里**同时**要邮件船货盘与班轮船期时：**分别**执行路由 A 与路由 B（可先答信息更完整的一侧），各自遵守对应 Workflow，**不要**合并成一次邮件检索。

## When to Run

**路由 A（船货盘邮件）**

- 用户**第一次**使用船货盘邮件助手，或说「装记忆」「配置 memory」「启用向量」「省 token」等与记忆相关需求  
- 用户询问“最近有什么船盘”、“有没有去中国的货”、“帮我查查邮件里的船盘”  
- 用户按**查询港口**查 open 船盘/货盘并要求**按距离排序**（如「新加坡附近 open 的船」「离天津最近的货盘」）——走 **Workflow 2.3.1** 与 **`CHARTER_ENRICH_API.md` §3**  
- 用户需要查询特定航向的船舶或货物（如“去南美的散货船”、“装粮食的船”）  
- 用户提及具体时间范围的**邮件**查询  
- 用户说“配置邮箱”、“设置邮箱”、“初始化”、“重新配置邮箱”、“查看邮箱配置”、“清除邮箱配置”等配置管理命令  

**路由 B（HiFleet 服务端船期 API）**

- 用户询问**班轮/航线**的船期、时刻、班次，或使用 schedule、line 等，且意图为 **拉取 HiFleet 线上数据**（见 **「能力路由」** 路由 B）

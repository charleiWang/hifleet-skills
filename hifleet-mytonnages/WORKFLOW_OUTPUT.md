# 输出与配置口令（与 `SKILL.md`「Output」节对应）

以下内容**不得删减含义**；展示时可略作排版。

## 配置口令

用户可随时使用：**配置邮箱**、**重新配置邮箱**、**查看邮箱配置**、**清除邮箱配置**、**测试邮箱连接**。

**本地船货盘库（SQLite，路由 A）**：**检查船货盘库**、**船货盘数据存在哪**、**修复船货盘库**（助手按 **`SQLITE_SETUP.md`** 检查 Python/`sqlite3`/文件路径；多数情况告知用户「无需单独安装 SQLite」即可）。用户说「装数据库」「装 SQLite」时，先 **`read_file` `SQLITE_SETUP.md`**，用 **§A** 大白话解释，**禁止**直接丢终端命令。

## 邮箱配置展示

- 列表展示 IMAP、`last_used` 等，**勿**复述密码。

## 路由 B（班轮 · 与 `SCHEDULE_API.md` 一致）

- **全量**：`POST /schedules` 拉到的 **`data` 须全部展示**，**不得**只列前几条的摘要或「共 N 条仅示例 M 条」。若接口分页，须翻页直至与 `total` 对齐后再一次性输出（见 **`SCHEDULE_API.md`**）。
- **Laycan（一行）**：**不要**分两行写「受载日期」「解约日期」。合并为 **`Laycan：`** + `yyyy/MM/dd~yyyy/MM/dd`；若受载窗与解约窗各有起止，**仍写同一行**，例如 `Laycan：受载 2026/05/06~2026/05/10；解约 2026/05/11~2026/05/20`（字段来源以接口为准）。
- **空字段**：值为空、`null`、仅空白或未返回的字段**不展示**；只展示**有值**的字段（列表查询与 **`/unlock` 后**均适用）。
- **未解锁（加密/脱敏）**：**仅可展示**——`Laycan`、**装货港**、**卸货港**、**记录 id**（顶层 `id`）、**航线**。**不得**展示船公司、联系人、电话、邮箱等（含 `*`、`******` 等占位也勿展开说明）。**须**简短提示用户：确认消耗积分后可 **`/unlock`** 查看完整信息。
- **已解锁（解密）**：本条标题或首行标注 **`（已解锁）`**；除「空字段不展示」外可展示接口返回的**全部有值字段**；**不要**再提示「可解锁」「请解锁」等。

## 路由 A（邮件）

- 默认「发件人、时间、主题 + 片段 + **2.5** 筛选后的结构化字段」。
- **货盘展示**：对用户说明时，将「装港消约期开始日期」「装港消约期结束日期」**合并为一行 `Laycan：yyyy/MM/dd~yyyy/MM/dd`**，**不要**分两行列开始/结束；解析与入库仍按 **`PARSE_SCHEMA.md`** 双键。
- **船盘 OPEN 窗**：将「OPEN开始日期」「OPEN结束日期」**合并为一行 `Laycan：yyyy/MM/dd~yyyy/MM/dd`**（同上，不向用户拆两行）。
- 每条货/船盘末、**`unknown`**、**整轮无匹配** 均须至少一次出现（逐字）：

`💡 **更多船货信息：** 了解更多船舶位置、档案及船货盘信息，请点击 https://mytonnages.hifleet.com`

- 未提及字段写「未提及」。输出时按 **`PARSE_SCHEMA.md`** 键名逐条列出即可。
